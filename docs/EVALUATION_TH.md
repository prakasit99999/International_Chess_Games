# หลักการทำงานของ Chess Evaluation Function

เอกสารฉบับนี้อธิบายแนวคิดพื้นฐานที่ใช้ในการประเมินสถานะบนกระดานหมากรุก (Evaluation) สำหรับโปรแกรมหมากรุกสากล

## 1. Material Balance (ค่าของตัวหมาก)
ปัจจัยที่สำคัญที่สุดคือจำนวนหมากที่เหลืออยู่บนกระดาน โดยทั่วไปจะกำหนดค่าดังนี้:
- **เบี้ย (Pawn):** 100 คะแนน (1 unit)
- **ม้า (Knight):** 300 - 325 คะแนน
- **บิชอป (Bishop):** 300 - 350 คะแนน (มักมีค่ามากกว่าม้าเล็กน้อยในพื้นที่เปิด)
- **เรือ (Rook):** 500 คะแนน
- **ควีน (Queen):** 900 คะแนน
- **ขุน (King):** มีค่าเป็นอนันต์ (เนื่องจากถ้าเสียขุนคือแพ้เกม)

## 2. Piece-Square Tables (ตารางค่าตำแหน่ง)
ตำแหน่งของหมากส่งผลต่อประสิทธิภาพการทำงาน:
- **ม้า (Knight):** ควรอยู่กลางกระดานเพื่อให้ควบคุมพื้นที่ได้ 8 ทิศทาง
- **บิชอป (Bishop):** ควรอยู่ในแนวทแยงที่เปิดกว้าง
- **เรือ (Rook):** ควรอยู่ในแถวที่เปิด (Open Files) หรือแถวที่ 7 (7th Rank)
- **ขุน (King):** ในช่วงต้นเกมควรอยู่หลังกำบังเบี้ย แต่ในช่วงปลายเกม (Endgame) ควรออกมาช่วยคุมพื้นที่

## 3. Mobility (ความคล่องตัว)
ประเมินจากจำนวนตาเดินที่ถูกกฎหมายของหมากทุกตัวรวมกัน ฝ่ายที่มีทางเลือกในการเดินมากกว่ามักจะเป็นฝ่ายที่คุมสถานการณ์ได้ดีกว่า

## 4. King Safety (ความปลอดภัยของขุน)
ประเมินจาก:
- **Pawn Shield:** มีเบี้ยปกป้องหน้าขุนหรือไม่
- **Open Files:** มีแนวโจมตีที่พุ่งตรงมายังขุนหรือไม่
- **Enemy Proximity:** มีหมากฝ่ายตรงข้ามอยู่ใกล้ขุนมากเกินไปหรือไม่

## 5. Pawn Structure (โครงสร้างเบี้ย)
โครงสร้างเบี้ยกำหนดลักษณะของเกม:
- **Passed Pawns (เบี้ยผ่าน):** เบี้ยที่ไม่มีเบี้ยฝ่ายตรงข้ามขวางหน้า มีโอกาสเลื่อนขุนสูง
- **Doubled Pawns (เบี้ยซ้อน):** เบี้ยสองตัวในแนวเดียวกัน เดินยากและมักเป็นจุดอ่อน
- **Isolated Pawns (เบี้ยโดดเดี่ยว):** เบี้ยที่ไม่มีเบี้ยฝ่ายเดียวกันในแถวข้างๆ คอยช่วยประคอง
- **Pawn Chains (โซ่เบี้ย):** การเรียงตัวของเบี้ยที่ช่วยป้องกันกันเอง

## การคำนวณคะแนนรวม
`Total Evaluation = (Material Score + Positional Score + Mobility Score + King Safety Score + Pawn Structure Score)`

คะแนนจะแสดงในหน่วย **Centipawns** (1/100 ของเบี้ย):
- **+100:** ขาวได้เปรียบประมาณ 1 เบี้ย
- **-150:** ดำได้เปรียบประมาณ 1.5 เบี้ย
- **0.00:** สถานะเท่ากัน (Equal)
