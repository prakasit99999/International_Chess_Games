# ตารางผลการทดสอบกรณี AI

เอกสารฉบับนี้สรุปผลการทดสอบระบบ AI ในส่วนของ Evaluation Function และ Search Algorithms

| รหัสกรณีทดสอบ | รายละเอียดกรณีทดสอบ                                                        | ผลที่คาดหวัง                                                | ผลที่ได้                                                             | สถานะ |
| ------------- | -------------------------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------- | ----- |
| TC-AI01       | ทดสอบ Evaluation Function ในสถานะกระดานที่กำหนด                            | ระบบให้คะแนนสอดคล้องกับความได้เปรียบของฝ่ายที่มีหมากมากกว่า | ระบบให้คะแนนเป็นบวกแก่ฝ่ายที่ได้เปรียบ และเป็นลบแก่ฝ่ายที่เสียเปรียบ | Pass  |
| TC-AI02       | ทดสอบการทำงานของอัลกอริทึม Minimax                                         | ระบบสามารถคำนวณและคืนค่าการเดินหมากที่ถูกต้องตามกติกา       | ระบบคืนค่าการเดินหมากที่ถูกต้องและไม่เกิดข้อผิดพลาด                  | Pass  |
| TC-AI03       | เปรียบเทียบผลลัพธ์ของ Minimax และ Alpha-Beta Pruning ภายใต้ Depth เดียวกัน | การเดินหมากที่ได้จากทั้งสองอัลกอริทึมควรเหมือนกัน           | การเดินหมากที่ได้เหมือนกัน และ Alpha-Beta ใช้จำนวนโหนดน้อยกว่า       | Pass  |

## รายละเอียดเพิ่มเติมของการทดสอบ (Technical Details)

- **TC-AI01**: ทดสอบโดยการนำตัวหมาก Queen ออกจากกระดาน และตรวจสอบค่าที่ได้จาก `Evaluation.Evaluate()`
- **TC-AI02**: ทดสอบการใช้ `Minimax.FindBestMove()` ในสถานะกระดานเริ่มต้น (Starting Position)
- **TC-AI03**: ทดสอบการเปรียบเทียบ `NodesEvaluated` ระหว่าง Minimax และ Alpha-Beta ที่ Depth 3 เพื่อยืนยันประสิทธิภาพของ Pruning
